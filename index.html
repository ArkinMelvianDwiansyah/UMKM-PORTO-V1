Pertanyaan yang Sering Diajukan (FAQ)

Teknologi apa yang digunakan oleh JalaninWeb?

Kami menggunakan standar modern kelas industri: Backend Laravel Framework yang tangguh dan berkeamanan tinggi, Tailwind CSS untuk styling responsif ultra-ringan tanpa CSS kembung/plugin lambat, serta arsitektur mobile-first dengan loading sub-second (< 1 detik) dan skor Google PageSpeed 90+.

Bisakah saya update konten website sendiri setelah jadi?

Tergantung paket yang Anda beli:
• Untuk Paket Growth (Rp 899.000) & Enterprise: BISA dan SANGAT MUDAH. Website dilengkapi Dashboard Admin CMS (Laravel CMS) mandiri untuk ganti foto/teks/katalog kapan saja tanpa paham coding.
• Untuk Paket Starter (Rp 399.000): Difokuskan sebagai landing page instan ultra-cepat dengan biaya hemat. Revisi konten minor dibantu via tim support WhatsApp atau bisa upgrade ke Growth kapan pun.

Bagaimana alur dan step pengerjaan website hingga online?

Alur pengerjaan transparan dalam 5 tahap: [1] Konsultasi WA menentukan paket → [2] DP 50% & Pengumpulan Materi (foto, teks, logo) → [3] Desain UI/UX & Coding Laravel + Tailwind → [4] Review Live Demo di HP & revisi sesuai jatah → [5] Pelunasan 50% & Serah Terima Penuh 100% hak milik website serta domain.

Berapa paket harga pembuatan website dan durasi pengerjaannya?

Tersedia 3 pilihan paket investasi transparan:
• Starter (Rp 399.000): 1–3 hari kerja, landing page 1 halaman responsif.
• Growth (Rp 899.000): 3–7 hari kerja, multi-halaman (3–6 halaman) + CMS Admin + Search Console.
• Enterprise (Custom Price): 2–4 minggu, sistem kustom, integrasi API & database kompleks.

Apakah ada biaya perpanjangan tahunan atau biaya tersembunyi?

Sama sekali tidak ada biaya tersembunyi. Biaya paket sudah all-in untuk 1 tahun pertama (Domain, Cloud Hosting NVMe, SSL HTTPS, jatah revisi). Perpanjangan sewa domain & hosting baru dimulai pada tahun kedua dengan biaya terjangkau dan transparan sesuai harga resmi registrasi.

Siapa yang memiliki hak kepemilikan atas website setelah jadi?

100% Hak Milik Anda. Bukan sistem sewa bulanan yang mengunci operasional bisnis Anda. Setelah serah terima dan pelunasan, seluruh akses registrar domain, akun hosting server, dan source code menjadi aset digital milik Anda seutuhnya tanpa ikatan tersembunyi.
