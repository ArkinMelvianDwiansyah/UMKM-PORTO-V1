ENTERPRISE FAQ & TEKNIS IMPLEMENTASI

Pertanyaan yang Sering Ditanyakan Calon Institusi

Penjelasan teknis mengenai keamanan data, bridging SatuSehat, WhatsApp Gateway, dan migrasi data lama.

Ya. Struktur input rekam medis menggunakan format standar SOAP (Subjective, Objective, Assessment, Plan) dan kamus kode diagnosa ICD-10 sesuai regulasi Permenkes No. 24 Tahun 2022. Struktur JSON database kami sudah disesuaikan dengan arsitektur FHIR SatuSehat Kemenkes RI (integrasi bridging API live ke server Kemenkes tersedia sebagai modul add-on tersendiri untuk klinik dengan sertifikat elektronik resmi).
Setiap kali dokter menyimpan E-Resep pada form SOAP, sistem otomatis mengurangi stok obat berdasarkan prinsip FEFO (First Expired, First Out). Batch obat yang masa kadaluarsanya kurang dari 90 hari otomatis diberi penanda merah/kuning di dashboard Apotek.
Sangat aman. Sistem menggunakan antrean Smart Delay Queue dengan variabel sapaan personal (Nama Wali Murid, Nama Siswa, NISN, dan Nominal Tagihan unik) sehingga tidak terdeteksi sebagai spam, serta mendukung WhatsApp Official Business API.
Ya. Modul KoperasiKu mendukung skema Jasa Bunga Flat / Efektif untuk KSP Konvensional maupun skema Akad Murabahah (Margin Jual Beli) & Mudharabah (Bagi Hasil) untuk BMT Syariah, lengkap dengan Kartu Angsuran Digital.
Tim implementasi kami menyediakan fitur 1-Click Import Excel (.xlsx / .csv) dan membantu proses migrasi seluruh database pasien, stok obat, daftar siswa, maupun saldo simpanan anggota secara gratis sampai siap pakai.
Bisa keduanya. Aplikasi bersifat responsif penuh (dapat dibuka dari Laptop kasir, Tablet dokter, maupun HP kepala sekolah/pengurus) dan tersedia dalam paket Cloud Berlangganan maupun Lisensi Beli Putus (Source Code & Server Milik Institusi Sendiri).
